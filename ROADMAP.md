# OZ-mosys roadmap

The idea: bring back the sound-design depth of the older plugins that are hard to find or no longer run
(Absynth 5, FM8, Massive), plus favourite parts of Absynth 6, Omnisphere, Pigments, Analog Lab, Serum and Kontakt -
each rebuilt in the OZ-mosys style. Priority goes to **making your own presets**: deep editing, routing and
customisation come before performance extras.

## Done
- v0.13: Morph pad (4 corner sounds, "Make B C D from this sound", per-corner Set / Dice) and Orb (Dice, Inertia, Attractor, Recorded path), loop slicer on the SAMPLER page (cut at the hits or 4/8/16/32 even slices, slices go on their own keys), Choke, coloured keyboard zones, Omnisphere patch importer.
- v0.6: Absynth-style browser + sound map, mutator, fine tuning, subpresets, ENV page (4 MSEGs),
  macro bar with Controls/Keys, live mod strip, Expansions page with installable `.ozpack` collections.
- v0.12: PLAY page - chords tool (key/scale/type/voicing, strum, humanize, chord circles) and 32-step arpeggiator with FM8-style rows, MIDI groove import, Arps & Chords bank.
- v0.11: FX rack page - 28 units in 10 categories, drag-and-drop, reorder, Low/High split, signal flow, IR loader, Half Time / Reverse / Stutter / Tape / Vinyl, FX Rack bank.
- v0.10: Performer mode for the breakpoint envelopes (16-32 curve steps, brush palette), wave editor (draw / harmonics, spectral morph start > end), Performer presets.
- v0.9: PATCH page - 2 module slots per engine, mod oscillator, coloured noise, feedback, dual filter, glide/velocity curves, Patch Lab bank, lighter memory use.
- v0.8: FM engine (6 operators, FM matrix, per-operator envelopes, 10 starting routings), FM Classics bank.
- v0.7: sound-type + mode chips, MIDI learn with links list, warp modes Formant / Steps / Fold, per-section mutation amount.
